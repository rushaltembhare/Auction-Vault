# Auction Vault

A luxury-themed online auction website for antique and collectible items.

## Run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the VS Code Live Server extension, or open it directly in a modern browser.

## Built with
- HTML5 and CSS3
- JavaScript
- React 18 (loaded from CDN)
- Babel Standalone (in-browser JSX transformation)
- jsPDF, jsPDF-AutoTable and Chart.js (CDN libraries)

## Included interface features
- Auction item listings and bidding interface
- Buyer and seller registration flows
- Seller document upload interface
- OTP and CAPTCHA demonstration flows
- Admin dashboard and PDF report interface
- Payment checkout demonstration UI

## Important demo limitations
This is a front-end demonstration. It does not include a production backend, real SMS/email OTP delivery, real CAPTCHA verification, secure server-side authentication, persistent shared auction data, or a live payment gateway. Data is stored in the browser, so it is not shared between users or devices. Do not enter real payment-card details or sensitive identity documents.

External libraries, fonts and some images load from third-party CDNs and require an internet connection.
